    How it works

    Four stages turn a long document into something you can review in a minute.

    1. Clean and split

    NLTK splits the text into sentences, keeping abbreviations like “Pvt. Ltd.” intact.

    2. Extract

    spaCy named entities plus regex rules find parties, dates, amounts, durations and governing law.

    3. Classify and flag

    A scikit-learn TF-IDF classifier labels each clause, and rules flag risky wording such as unlimited liability.

    4. Summarize

    TF-IDF ranks the most informative sentences. A Hugging Face model can add an abstractive summary.

    Built with Flask, spaCy, NLTK, scikit-learn, Pandas and Hugging Face Transformers. A study aid, not legal advice.
